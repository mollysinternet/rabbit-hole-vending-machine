# rabbit hole vending machine

insert a coin. discover something weird.

## publish

1. create a GitHub repository named `rabbit-hole-vending-machine`.
2. upload `index.html` to the root of the repository.
3. open **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. visit `https://mollysinternet.github.io/rabbit-hole-vending-machine/` after GitHub Pages finishes publishing.

## edit topics

Edit the `topics` list near the bottom of `index.html`. Each entry is a Wikipedia article title. Wikipedia supplies article previews and images when available. If the API cannot be reached, the card still links to the article.
